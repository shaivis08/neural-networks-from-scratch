# Neural Networks

This directory contains my implementations and experiments while learning neural networks with PyTorch.

The goal is to understand the building blocks of neural networks by implementing and experimenting with them rather than directly relying on high-level APIs.

## Contents

### `basic_nn.ipynb`
Covers the basic components of a neural network:

- `nn.Module` and defining a model
- `nn.Linear`
- Forward pass
- Loss functions
- Backpropagation and gradients
- Gradient descent
- Optimizers
- Training over multiple epochs

The notebook includes small experiments to understand how model parameters, gradients, loss, and optimization interact.

## Learning Progress

Currently focusing on understanding the fundamentals before moving on to deeper architectures and more complex models.
